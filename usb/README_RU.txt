AOKZOE A2 (Ryzen 7 7840U), BIOS 1.16: объём видеопамяти (VRAM / UMA) без прошивки BIOS. Версия 3
=================================================================================================

Почему не сработала версия 1:
  В BIOS AOKZOE есть собственный код (модуль AmdNbioDxe). При каждой загрузке он берёт объём VRAM
  из байта CMOS 0x7A и перезаписывает им настройку AMD CBS:
    0x7A = 00         -> авто: объём зависит от модели (у тебя 6 ГБ). Так стоит с завода
    0x7A = 01         -> используется значение AMD CBS
    0x7A = 02..C0     -> VRAM = значение x 256 МБ (04=1G, 08=2G, 0C=3G, 10=4G, 18=6G, 20=8G, 28=10G, 30=12G, 38=14G, 40=16G)
  Если новое значение отличается от текущего, BIOS записывает его и САМ перезагружает приставку
  один раз. Это нормально.
  Скрипты версии 2 пишут байт CMOS 0x7A и для согласованности то же значение в AMD CBS.

Подготовка:
  Флешка FAT32. Скопируй ВСЁ содержимое архива в корень флешки (старые файлы удали).
  Secure Boot в BIOS должен быть выключен.

Применение:
  1. Загрузись с флешки. Появятся текущие значения.
  2. Набери команду, например vram_4g.nsh, и нажми Enter.
     Есть vram_1g / 2g / 3g / 4g / 6g / 8g / 10g / 12g / 14g / 16g.nsh и vram_auto.nsh (вернуть заводское).
  3. Проверь, что строка CMOS показывает нужное значение (например 0x10 для 4G).
  4. Набери reset и вытащи флешку. Приставка может сама перезагрузиться ещё раз, это нормально.
  5. В Windows: Диспетчер задач -> Графический процессор -> "Выделенная память GPU".

Рекомендации:
  При 16 ГБ ОЗУ разумный максимум 4-6 ГБ (с завода 6 ГБ). 8 ГБ оставит Windows только 8 ГБ.
  При 32 ГБ ОЗУ: 8 ГБ оптимально, 12 ГБ — если игре не хватает VRAM, 16 ГБ — максимум (Windows останется 16 ГБ).

Откат:
  - vram_auto.nsh: заводской режим.
  - Если сядет батарейка часов или сбросится CMOS, байт станет 00, то есть заводской режим.
    Тогда просто повтори скрипт.

Только для AOKZOE A2 7840U, BIOS 1.16. Другие адреса не трогай.
